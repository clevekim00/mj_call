# AI 통화 프롬프트 — 계획 자산, 미연결

이전 구현에는 자동 통화 모델과 별도 시스템 프롬프트가 없었습니다. 아래 템플릿은 기존 기획을 기반으로 이번 분리 작업에서 새로 작성했습니다. 현재 네이티브 앱에서는 로드하거나 실행하지 않습니다.

1. `prepare.md`: 목적을 질문·완료 조건·승인 조건으로 구조화.
2. `call-agent.md`: 상대 발언을 보고 다음 응답 또는 사용자 질문 제안.
3. `review.md`: 확인된 답·미해결 항목·결과 근거 정리.

대화 원문과 사용자 입력은 신뢰하지 않는 데이터로 별도 전달합니다. 승인·개인정보·범위 검사는 프롬프트 외부 코드가 집행해야 합니다. 실제 API 키·실사용 통화 예시를 이 폴더에 저장하지 않습니다.
