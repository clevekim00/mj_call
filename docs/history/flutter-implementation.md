# 통화 도우미 — 수동 통화 보조 1차 구현

2026-11-02. 별도 전화기로 발신하고, 아이패드·PC가 글을 대신 읽고 마이크로 녹음하는 기능이다. AI 자동 응답과 상대 말의 자동 전사는 이번 구현에 포함하지 않는다.

## 메뉴와 사용법

1. **오늘 → 통화 도우미 → 새 통화 준비**에서 기관·고객센터, 전화번호, 문의 목적, 질문을 적는다. 필요 서류·신청 방법·접수 기한·담당 부서 질문을 버튼으로 추가할 수 있다.
2. ‘준비만 저장’으로 보관하거나 ‘저장하고 통화 보조 열기’로 진행한다. 준비와 최근 통화는 앱을 다시 열어도 남는다.
3. ‘전화 걸기 전 소리 점검’으로 한국어 음성과 음량을 확인한다. 블루투스·헤드폰 출력 대신 전화기 마이크가 들을 수 있는 스피커 출력인지 확인한다.
4. 별도 전화기에서 발신하고 스피커폰을 켠 뒤 준비 확인란을 선택한다. 앱이 실제 전화기를 조작하거나 연결 상태를 감지하지는 않는다.
5. 글을 입력하고 ‘입력한 글 말하기’를 누르거나 준비 문장을 선택한다. 누른 문장만 한국어로 읽는다. 전달 허용 정보는 자동 낭독하지 않는다. ‘즉시 말하기 중지’는 진행 중인 발화와 대기 중인 발화를 취소한다.
6. 녹음이 필요하면 ‘녹음 허락 요청 말하기’로 안내한다. 사용자가 허락을 확인한 뒤 확인란을 선택하고 ‘녹음 시작’을 누른다. ‘녹음 중지·저장’으로 여러 구간을 남길 수 있다.
7. 문의 결과와 답변·기한·접수번호 등을 직접 메모한다. 전화기에서 실제 통화를 종료한 후 ‘통화 마치고 기록 저장’을 누른다. 앱은 전화를 끊지 않는다.
8. **통화 도우미 → 준비한 문의·최근 통화**에서 준비를 이어서 사용하고 녹음을 재생·중지하거나 기록과 녹음을 삭제한다. **기록 화면 상단 전화 아이콘**으로도 접근한다.

## 저장과 실패 처리

- 준비·메모·결과·오디오 연결 정보는 SharedPreferences의 `call_assist_records_v1`, 음원은 앱 문서 폴더의 `recordings/call_assist_<uuid>.m4a`에 저장한다.
- 이 기능은 별도 AI 서버로 내용을 전송하지 않는다. OS의 한국어 음성 설치·사용 가능 여부에 따라 TTS가 실패할 수 있다. 앱 저장소는 별도의 암호화 보관함으로 구현한 것이 아니며 기기 백업 정책의 적용을 받을 수 있다.
- 녹음은 보조 기기의 마이크 소리다. 회선의 양측 원본 음성을 분리 저장하는 기능은 아니다. 자기 스피커 소리와 주변 소음이 섞이거나 억제될 수 있다.
- 마이크 권한 거절·시작 실패·빈 파일·저장 실패를 표시한다. 파일을 얻은 뒤 기록 저장에 실패하면 화면에 보존하고 ‘저장 다시 시도’를 제공한다.
- 화면 잠금·앱 이동 시 말하기와 녹음을 멈추고 저장을 시도한다. 녹음 장치가 중단되면 상태를 점검해 가능한 구간을 저장하고 불완전 표시를 남긴다. 자동 재시작하지 않는다.
- 강제 종료·전원 차단·저장 공간 부족에서는 마지막 녹음의 복구를 보장하지 않는다. 이탈 시 저장 완료를 확인한다.
- 녹음을 하지 않은 통화도 준비·메모·결과는 저장할 수 있다. 녹음 누락은 문의 결과와 별도로 남긴다.
- 삭제는 사용자가 지정한 통화 기록과 이 기능이 생성한 음원에 한정한다. 자동 30일 삭제·클라우드 동기화·음원 내보내기는 아직 제공하지 않는다.

## 플랫폼과 구현

- 네이티브 Flutter 앱의 아이패드(iOS), macOS, Windows 경로를 구현했다. 브라우저 지원은 이번 단계에 포함하지 않는다.
- iOS는 기존 마이크 녹음 채널과 통화 보조 전용 AVSpeechSynthesizer를 사용한다. 녹음 세션을 불필요하게 비활성화하지 않고 발화 완료·취소를 Dart에 알린다.
- PC TTS는 flutter_tts, 녹음은 record를 사용한다. 재생은 iOS·macOS의 기존 네이티브 채널, 나머지 네이티브 플랫폼의 audioplayers를 사용한다.
- 공급자 기반 목소리 목록·속도 설정·음성 복제·STT·자동 ARS·자동 대화는 후속 기능이다. 현재 속도는 고정이며 목소리는 기기의 기본 한국어 음성이다.
- 테스트는 오디오 장치를 대체한 단위·화면 테스트다. 실제 기기의 음성 출력과 마이크 동시 사용, 통신사·전화기 조합, Windows 빌드·실행은 별도 검증해야 한다.
