# 구현한 기능과 구현할 기능

## 2026-11-03 네이티브 이관 상태
네이티브 소스를 작성한 것과 해당 OS에서 검증한 것은 별도다. 전체 기능이 모든 기기에서 검증된 출시 버전이 아니다.

| 기능 | Apple | Android | Windows |
|---|---|---|---|
| 독립 네이티브 프로젝트 | 작성 | 작성 | 작성 |
| 기관·고객센터 문의 준비·로컬 저장 | 작성 | 작성 | 작성 |
| 직접 입력·준비 문장 한국어 TTS | 작성 | 작성 | 작성 |
| 말하기 중지 | 작성 | 작성 | 작성 |
| 녹음 허락 확인·마이크 녹음 | 작성 | 작성 | 작성 |
| 녹음 중지·저장·재생·삭제 | 작성 | 작성 | 작성 |
| 문의 결과·메모 | 작성 | 작성 | 작성 |
| 화면 이탈 처리 | background 저장 시도 | onPause 저장 시도 | 창 닫기 시 저장 시도 |
| 실제 빌드 확인 | 아래 검증 기록 참고 | 로컬 Android SDK 없음 | 로컬 .NET/Windows 없음 |
| 실제 스피커폰 통화 품질 | 미검증 | 미검증 | 미검증 |

빌드 결과는 docs/VALIDATION.md에 기록한다. GitHub Actions는 세 플랫폼 컴파일을 재현한다. 서명·배포는 수행하지 않는다.

## 이전 구현에서 이관한 자료
- Flutter 수동 통화 보조 전체 코드, 관련 테스트, 오디오·권한 서비스.
- 원본 앱 통합 변경 패치와 SHA-256 이관 목록.
- 기획 Blueprint와 기존 구현 안내.
- 기존 Flutter 테스트 16개 및 iOS/macOS 빌드 성공은 역사 자료다. 네이티브 테스트 통과로 계산하지 않는다.

## 다음 구현 우선순위
1. 네이티브 앱별 단위·UI 테스트, 실기기 마이크/TTS 동시 출력, 녹음 중단·누락·디스크 오류 검증.
2. 플랫폼 간 데이터 스키마 버전, 녹음 무결성 검사, 저장 실패 재시도, 강제 종료 복구.
3. 큰 글자·키보드·스크린리더·스위치 입력과 고정 중지 버튼 검증, 음성 선택·속도 설정.
4. 실시간 상대 음성 인식·자막, 에코 처리·겹침 처리.
5. 목적 기반 AI 질문/응답 제안, 사용자 승인 UI 및 코드 정책 검사.
